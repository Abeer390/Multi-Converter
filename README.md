Multi-Converter system is a project which main aims is developing a software which can use 
many calculating purposes. It has many facilities like currency conversion, weight conversion,
length conversion and area conversion. Currency conversion means user can use this to
converting one currency to another currency such as usd,euro,pound etc. Similarly weight 
conversion means user can convert one weight unit to another weight unit. Again the length 
converter helps to converting one length unit to another length unit. On the other hand area 
converter is use to calculating area of geometric shapes such as circle,square,rectangle and so on.
